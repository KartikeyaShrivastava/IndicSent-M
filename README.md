# IndicSent-M
Multimodal sentiment analysis for Bengali memes using text, images, or both, with XLM-RoBERTa, ResNet-50, and explainable predictions.  A slightly longer project summary: IndicSent-M classifies meme sentiment as positive, neutral, or negative. It compares text-only, image-only, and multimodal models—including bidirectional cross-attention
